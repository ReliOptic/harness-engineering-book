# DR-2.3 Model Distillation and Tool Use Summary

## 1. 서론: DR-2.3 설계 요건과 대규모 언어 모델 압축의 필연성
- 자율형 에이전트의 실시간 함수/도구 호출 시 발생하는 응답 지연을 해결하기 위해, 모델 증류(Distillation)와 양자화(Quantization) 같은 모델 압축 기술 도입이 필수적임.

## 2. 함수 호출 정확도의 평가 메커니즘과 지표의 한계
- 함수 호출 능력을 정확히 평가하기 위해, 단순 텍스트 유사도를 넘어 추상 구문 트리(AST)를 활용하여 JSON 문법, 함수 이름, 매개변수 타입과 값을 다단계로 엄격히 검증함.

## 3. 양자화(Quantization)가 도구 호출 안정성에 미치는 역학적 파괴 현상
- 4-bit 등의 저정밀도 양자화는 다수의 도구 중 적절한 도구를 선택하는 '도구 공간 해상도'를 심각하게 훼손함.
- 어텐션 연산의 근사 오차로 인해 따옴표 누락과 같은 치명적인 JSON 구문 오류가 증가함.
- 단순 정확도 지표로는 파악되지 않는 무작위 '플립(Flips)' 현상(정답이 오답으로, 오답이 정답으로 뒤바뀌는 현상)이 빈번하게 발생하여 시스템 신뢰성을 무너뜨림.

## 4. 모델 증류(Model Distillation)가 함수 호출 역량에 미치는 영향 및 한계
- ODIA 프레임워크와 같이 단순 질의는 소형 증류 모델로, 복잡한 질의는 대형 모델로 분기시켜 응답 지연 시간을 혁신적으로 단축함.
- 그러나 다수 모델이 소수 교사 모델에 의존해 증류될 경우 '모델 동질화'를 유발하여, 처음 접하는 API(제로샷)에 대한 대처 능력이 상실되는 부작용이 발생함.

## 5. 도구 호출 안정성 복구를 위한 전략적 접근
- **제한적 해독(Constrained Decoding):** 외부 파서로 JSON 형식을 강제하지만, 이는 확률 분포를 왜곡하여 환각을 낳을 수 있으므로 `chain_of_thought` 필드를 추가해 추론 여백을 확보해야 함.
- **구조적 훈련 내재화:** 강화학습(RL)을 통해 모델 스스로 복잡한 스키마를 준수하도록 훈련(Think Inside the JSON)하는 방식이 각광받고 있음.

## 6. 고급 훈련 패러다임: 양자화 인지 증류(QAD)와 하이브리드 최적화
- 사후 양자화(PTQ)의 부작용을 극복하기 위해, 훈련 시 교사 모델의 확률 분포(Soft Labels)를 직접 모방하는 '양자화 인지 증류(QAD)' 기법이 도입되어 압축 모델의 도구 호출 성능을 베이스라인 수준으로 완벽히 복구함.

## 7. 시스템 아키텍처 및 배포를 위한 종합 설계 제언
- 모델 평가 시 AST 검증과 KL 발산(KLD) 등의 거리 지표 활용.
- 구조적 무결성 유지를 위한 양자화 비트 하한선(예: 8-bit 또는 NVFP4) 설정.
- 질의 난이도에 따른 이중 아키텍처 라우팅과 QAD를 전면 도입하여 시스템의 효율성과 안정성을 모두 확보해야 함.

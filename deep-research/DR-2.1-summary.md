# DR-2.1 LLM Agent Benchmarks Summary

## 대규모 언어 모델의 자율 에이전트화와 평가 패러다임의 전환
- 단순 질의응답을 넘어 외부 도구를 자율적으로 활용하는 에이전트 시스템으로 AI가 발전함.
- 기존의 정적 벤치마크 한계를 극복하기 위해, 에이전트의 에러 복구 능력과 동적 상호작용을 평가하는 SWE-bench, WebArena, ToolBench가 차세대 표준으로 자리 잡음.

## SWE-bench: 소프트웨어 엔지니어링 에이전트의 문제 해결 및 행동 패턴 분석
- 실제 GitHub 이슈를 기반으로 코드베이스 탐색 및 버그 수정 패치 능력을 평가. 데이터 오염 방지를 위해 Verified, Pro 등으로 진화함.
- 모델별로 도구 사용 전략이 상이함. Claude 모델은 선별적 탐색으로 맥락을 유지하고, 최신 OpenAI 모델들은 광범위한 검색으로 높은 정확도를 추구함. 소형 오픈소스 모델은 셸 구문 오류와 고착 현상에 취약함.

## WebArena: 동적 웹 탐색 및 상호작용 환경에서의 행동 분석
- 텍스트를 넘어 실제 웹 환경에서의 '기능적 정확성'을 평가함.
- 심층 분석 결과, 에이전트들이 복잡한 상황에서 조기 종료 및 성취 불가능성에 대한 환각, 무한 루프 및 고착, 네비게이션 예외 처리 실패, 정보 추출 실패 등의 행동적 오류 패턴을 보임.

## ToolBench: 복잡한 도구 사용 및 API 오케스트레이션 성능 분석
- 수천 개의 RESTful API 환경에서 에이전트의 도구 선택과 다단계 호출 능력을 과정 중심으로 평가.
- 전략적 계획 수립 능력은 뛰어나나 전술적 실행 능력이 부족한 괴리 현상이 관찰됨. 모델마다 오케스트레이션 성향(Claude의 주도성, GPT-4o의 신중함, Gemini의 병렬 처리 안정성)에 뚜렷한 차이가 있음.

## 독점(Proprietary) 모델과 오픈소스(Open-source) 모델의 에이전트 행동 지형도
- 최신 오픈소스 모델(DeepSeek, Llama 4 등)의 발전으로 독점 모델과의 성능 격차가 급격히 줄어들며 압도적인 비용 절감 효과를 제공함.
- 독점 모델의 과잉 차단 현상과 오픈소스 모델의 유연성이 대비되며, 플래너는 독점 모델이, 실행기는 오픈소스 모델이 맡는 하이브리드 아키텍처로 수렴 중임.

## 다중 에이전트 시스템의 치명적 실패 유형 및 보안 취약성
- 에이전트의 자아 모델 부재로 인한 극단적 파괴 행동(예: 전체 서버 삭제)과, 다중 에이전트 환경에서 발생하는 오류의 연쇄 증폭 현상이 보고됨.
- 무한 루프로 인한 시스템 자원 고갈 공격, 내부 논리와 외부 시스템 상태 간의 불일치 등 에이전트 특유의 보안 취약성이 존재함.

## 결론 및 향후 전망
- 모델 자체의 추론 능력이 에이전트의 실행 신뢰성과 안전성을 보장하지 않음이 벤치마크들을 통해 입증됨.
- 향후 에이전트 평가 및 개발 패러다임은 결과 중심주의(Outcome-supervised)에서 벗어나, 안전하고 통제 가능한 과정 중심 감독(Process-supervised) 패러다임으로 전환되어야 함.

# /integrate [chNN]

해당 챕터의 모든 섹션을 통합하여 하나의 완성된 챕터로 만든다.

## 실행 단계

1. `chapters/chNN-xxx.md`에서 모든 섹션을 읽는다.
2. 섹션들을 순서대로 합친다.
3. 챕터 도입부를 작성한다.
4. 챕터 마무리를 작성한다.
5. 섹션 간 전환의 매끄러움을 확인하고 다듬는다.
6. 학습 결과 달성 여부를 자가 점검하고 보고한다.

## 도입부 형식

- "이 챕터에서 무엇을 관찰할 것인가"
- 핵심 질문 1~2개 제시
- 분량: 150~200자

## 마무리 형식

- "이 챕터에서 관찰한 것의 요약" (3~5문장)
- "다음 챕터 예고" (1~2문장)
- 분량: 200~300자

## 학습 결과 자가 점검

`chapter-map.md`에 정의된 학습 결과를 기준으로:
- [ ] 각 학습 결과가 챕터 내에서 달성되었는가?
- [ ] 달성 근거가 되는 섹션을 명시한다.
- [ ] 미달성 항목은 보완 필요 사항으로 보고한다.

## 사용 예시

```
/integrate ch01
/integrate ch04
```

# Ch.5 대화 프롬프트 — 왜 다섯 변수인가: 현장에서의 정당화

## 프로젝트 컨텍스트

나는 "Harness Engineering and AgentOps"라는 기술서를 집필 중이다. 이 책은 2026년 상반기 agent runtime의 실패를 관찰하고 측정하는 실험서다. 11챕터, 4-Part 구조이며, Part II(Ch.5~7)는 Part I에서 확립한 학술적 기반 위에 관찰과 측정의 프레임워크를 세운다.

Ch.5는 Part II의 첫 번째 챕터로, "왜 agent runtime의 병목 분석에 최소 5개 변수가 필요한가"를 현장 관찰로 정당화한다. 이 5변수는: **모델(model), harness, product surface, 운영자 개입(operator intervention), 연산/자원(compute)**이다. 이 챕터는 논문이 아닌 **이 책 고유의 프레임워크**이므로, 외부 자료보다 현장 관찰과 논리적 논증이 핵심 재료다.

**이 대화의 목적**: 5변수 프레임워크의 논리적 필연성을 검증한다. "왜 4개가 아니라 5개인가", "왜 6개가 아닌가"를 내가 스스로 논증할 수 있어야 한다. 이 논증 과정이 Ch.5 §3의 핵심 서사가 된다.

## 10가지 평가 질문

나의 이해도를 평가해 주세요. 각 질문에 대해 내가 답하면, 논리적 빈틈을 짚어주고, 더 정밀한 논증이 필요하면 보충 질문을 던져 주세요. 모든 질문이 끝나면, 내 답변 과정에서 드러난 논증 패턴을 종합하여 Ch.5 집필에 활용할 수 있는 insight summary를 만들어 주세요.

### Part I에서 현장으로 (기술사 합류)

1. **네 갈래의 합류**: Part I의 네 기술사(attention, compression, alignment, tool-use/memory)가 agent runtime이라는 한 지점에서 만난다고 할 때, 각각이 runtime에서 어떤 형태로 나타나는지 설명해 보세요. 이들이 독립적으로 작용하나요, 아니면 상호작용하나요?

2. **단일 변수 설명의 실패**: "agent가 실패하면 모델 때문이다"라는 주장이 왜 부족한지, 구체적 반례를 들어 설명해 보세요. 모델이 최고 성능이어도 실패하는 시나리오는?

3. **이원론의 한계**: "모델 vs. 모델 바깥 전부"라는 이분법이 왜 불충분한지 설명해 보세요. 이 이분법이 놓치는 것은 무엇인가요?

### 5변수의 필연성

4. **모델 변수의 독립성**: 모델의 추론 능력, 도구 사용 정확도, 일관성, 캘리브레이션은 다른 4개 변수와 독립적으로 측정 가능한가요? 모델을 교체하면 나머지 4개 변수의 측정값이 바뀌나요, 안 바뀌나요?

5. **Harness 변수는 왜 모델과 분리해야 하는가**: harness(메모리 보호, 권한 관리, 복구 메커니즘, 평가 hook)를 모델의 일부로 볼 수 없는 이유를 설명해 보세요. Ch.3에서 논의한 "학습-런타임 경계"가 여기서 어떻게 작용하나요?

6. **Surface 변수는 왜 독립적인가**: 같은 모델 + 같은 harness인데, CLI에서 실행할 때와 API webhook으로 실행할 때 결과가 다른 이유를 설명해 보세요. surface를 harness에 포함시킬 수 없는 이유는?

7. **Operator intervention은 왜 변수인가**: "인간의 개입"을 측정 가능한 변수로 취급해야 하는 이유를 설명해 보세요. 개입 없음 / 힌트 / 직접 수정 — 이 세 조건에서 agent 성능이 어떻게 달라지나요?

8. **Compute 변수의 독립성**: 모델, harness, surface, 개입이 모두 최적인데 연산 자원이 부족하면 어떤 일이 벌어지나요? 이것이 다른 4개 변수로 환원될 수 없는 이유는?

### 프레임워크 경계 검증

9. **왜 6개가 아닌가**: 여섯 번째 변수 후보(예: 데이터 품질, 네트워크, 보안)를 제안하고, 그것이 왜 기존 5개에 포함되거나 이 책의 범위 밖인지 스스로 논증해 보세요.

10. **Agent-1 → Agent-2 전환**: 5변수 프레임워크 위에서, Agent-1(외부 harness + 운영자 의존)에서 Agent-2(자기 모니터링 + 자기 복구)로의 전환이 5개 변수 중 어떤 것들의 재배치를 의미하는지 설명해 보세요. 이 재배치가 왜 "harness가 사라지는 것"이 아니라 "harness가 agent 내부로 이동하는 것"인지?

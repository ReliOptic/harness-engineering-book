# /voice-check [chNN]

해당 챕터의 문체를 점검하고 위반 사항을 보고한다.
기준: 서울대·KAIST급 이공계 교수 텍스트북 문체. 문장 길이는 무관하다 — 길어도 인과가 내장되어 있으면 통과, 짧아도 나열이면 위반이다.

---

## 점검 항목

### A. AI 문체 8대 증상

**A1. 단문 나열**
짧은 독립 문장 3개 이상이 연속되는 패턴을 찾는다.
"A였다. B였다. C였다." 형식. 각 문장이 앞 문장을 받지 않고 독립적으로 서 있으면 위반.

**A2. 번호 나열**
"첫째", "둘째", "셋째" 또는 "1.", "2.", "3." 구조가 산문 안에 있는가.
표(table)와 목록이 명시적으로 필요한 곳은 제외.

**A3. 설교조 종결**
문장이 "~이 중요하다", "~해야 한다", "~임을 알 수 있다", "~이 필요하다"로 끝나는가.
분석의 귀결이 아닌 선언으로만 서 있으면 위반.

**A4. 괄호 설명 남발**
이미 앞에서 소개된 용어에 다시 괄호 설명이 붙어 있는가.
"GC(Garbage Collection)가" — 두 번째 이후 등장이면 위반.

**A5. 메타 전환 어구**
"이처럼", "위에서 살펴본 바와 같이", "다음으로는 ~을 살펴보겠다", "앞서 언급한 바와 같이"가 있는가.
논리가 흐르면 전환 어구가 필요 없다.

**A6. 동일 주어 반복**
같은 주어가 연속 3문장 이상 문두에 반복되는가.

**A7. 선언형 결론**
섹션이나 문단의 마지막 문장이 "따라서 X가 필요하다/중요하다/확인되었다" 형식인가.
관찰이 결론을 만들면 결론을 다시 선언할 필요가 없다.

**A8. 대칭 반복 구조**
"A는 B이다. C는 D이다. E는 F이다." 동일 문장 구조가 3회 이상 반복되는가.

---

### B. 내용 검사

**B1. Hype 표현**
"혁신적", "획기적", "전례 없는", "revolutionary", "game-changing", "unprecedented" 또는 유사 형용사.

**B2. 수치 없는 성능 서술**
"성능이 떨어졌다", "훨씬 빠르다", "대폭 개선됐다" 등 측정값 없는 변화 서술.
→ 실험 ID + 구체적 수치로 교체 제안.

**B3. 5변수 누락**
시스템 실패나 병목을 논하는데 5변수(모델, harness, surface, intervention, compute) 중 어떤 변수가 1차 원인인지 명시되지 않은 곳.

**B4. 실험 인용 형식**
실험 결과를 인용하면서 실험 ID(ENN)가 없는 곳.

## 출력 형식

```
## Voice Check 결과 — chNN

### 위반 사항
1. [A1 단문 나열] 섹션 N, N번째 단락:
   문제: "A였다. B였다. C였다."
   제안: "A가 B를 야기했고, 이 B는 C라는 조건에서만 발생하는 패턴이었다."

2. [A3 설교조 종결] 섹션 N:
   문제: "따라서 harness 설계가 중요하다."
   제안: 없앤다. 앞 문단의 관찰이 결론을 이미 만들었다.

3. [B2 수치 없는 서술] 섹션 N:
   문제: "응답 속도가 크게 개선되었다."
   제안: "p95 응답 시간이 4.2초에서 1.8초로 줄었다(E07)."

### 통과 항목
- A2, A4, A5, A6, A7, A8 — 위반 없음
- 모든 실험 인용에 ID 포함

### 총 위반: N건 (A계열 N건, B계열 N건)
```

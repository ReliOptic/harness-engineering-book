# /voice-check [chNN]

해당 챕터의 문체를 점검하고 위반 사항을 보고한다.

## 점검 항목

### 1. 문장 길이
- 40자 초과 문장을 모두 찾는다.
- 위치(섹션, 단락)와 문장 전문을 보고한다.
- 수정 제안을 한다.

### 2. Hype 표현
다음 표현 또는 유사 표현을 찾는다:
- "revolutionary", "game-changing", "unprecedented"
- "획기적", "혁신적", "전례 없는"
- 과장된 형용사

### 3. 회피 표현
다음 패턴을 찾는다:
- "~하는 것이다"
- "~라고 할 수 있다"
- "~라고 볼 수 있다"
- "~일 것으로 생각된다"

### 4. 5변수 프레임워크 누락
- 병목이나 실패를 논하는데 5변수(모델, harness, surface, intervention, compute) 중 어떤 변수인지 명시하지 않은 곳.

### 5. 수치 없는 성능 서술
- "성능이 떨어졌다", "느려졌다", "개선되었다" 등 수치 없는 변화 서술.
- "측정값 필요" 또는 관련 실험 참조 제안.

### 6. 실험 인용 형식
- 실험 결과를 인용하면서 실험 ID(ENN)를 명시하지 않은 곳.

## 출력 형식

```
## Voice Check 결과 — chNN

### ❌ 위반 사항
1. [문장 길이] 섹션 N, N번째 단락: "..." (58자)
   → 제안: "..." / "..."

2. [hype 표현] 섹션 N: "혁신적인 접근"
   → 제안: "관찰된 효과는..."

### ✅ 통과 항목
- 모든 실험 인용에 ID 포함
- ...

### 총 위반: N건
```

## 사용 예시

```
/voice-check ch01
/voice-check ch03
```

# /revise [chNN] [section_number] "[피드백 내용]"

피드백을 반영하여 해당 섹션을 수정한다.

## 실행 단계

1. `chapters/chNN-xxx.md`에서 해당 섹션 원본을 읽는다.
2. 피드백 방향에 따라 수정한다.
3. 수정 전후를 diff 형식으로 보여준다.
4. 문체 규칙 위반이 있으면 함께 수정한다.

## 수정 시 체크리스트

문장 길이는 기준이 아니다. 짧아도 나열이면 위반, 길어도 인과가 내장되어 있으면 통과.

**AI 문체 8대 증상 (이 중 하나라도 해당하면 수정)**

- [ ] A1. 짧은 독립 문장이 3개 이상 연속 → 인과를 연결한 하나의 문장으로 합친다
- [ ] A2. "첫째/둘째/셋째"가 산문 안에 있음 → 흐름 안의 논증으로 전환한다
- [ ] A3. "~이 중요하다", "~해야 한다", "~임을 알 수 있다"로 끝나는 문장 → 없앤다
- [ ] A4. 이미 소개된 용어에 괄호 설명이 다시 붙음 → 괄호 제거
- [ ] A5. "이처럼", "위에서 살펴본 바와 같이", "다음으로는" → 전부 없앤다
- [ ] A6. 동일 주어가 3문장 이상 반복 → 합치거나 주어 생략
- [ ] A7. 마지막 문장이 "따라서 X가 필요하다/중요하다/확인되었다" → 없앤다
- [ ] A8. 동일 문장 구조(A는 B다. C는 D다.)가 3회 이상 반복 → 두 번째부터 변형

**내용**

- [ ] hype 표현("혁신적", "획기적") → 제거
- [ ] 수치 없는 성능 서술 → 실험 ID + 구체적 수치 또는 "측정 필요" 표시
- [ ] 5변수 없이 병목을 논함 → 변수 명시
- [ ] 실험 인용에 ID 없음 → ENN 추가

## diff 출력 형식

```
--- 원본
+++ 수정
@@ 변경 위치 @@
- 삭제된 내용
+ 추가된 내용
```

# /revise [chNN] [section_number] "[피드백 내용]"

피드백을 반영하여 해당 섹션을 수정한다.

## 실행 단계

1. `chapters/chNN-xxx.md`에서 해당 섹션 원본을 읽는다.
2. 피드백 방향에 따라 수정한다.
3. 수정 전후를 diff 형식으로 보여준다.
4. 문체 규칙 위반이 있으면 함께 수정한다.

## 수정 시 체크리스트

- [ ] 40자 초과 문장이 있는가 → 분리
- [ ] hype 표현이 있는가 → 제거
- [ ] 회피 표현("~하는 것이다")이 있는가 → 직접 표현으로
- [ ] 수치 없는 성능 서술이 있는가 → 구체적 수치 추가 또는 "측정 필요" 표시
- [ ] 5변수 프레임워크 없이 병목을 논하는가 → 변수 명시
- [ ] 전환 문장이 자연스러운가

## diff 출력 형식

```
--- 원본
+++ 수정
@@ 변경 위치 @@
- 삭제된 내용
+ 추가된 내용
```

## 사용 예시

```
/revise ch01 2 "수치가 없어서 막연함. E01 결과를 인용해줘."
/revise ch03 1 "톤이 너무 학술적. 현장 엔지니어가 말하는 것처럼 바꿔."
```

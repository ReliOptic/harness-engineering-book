## SD-001 — Ch.2 구조 재편: 벤치마크 역사 리뷰 선행

**날짜**: 2026-03-27
**변경 내용**: Ch.2 섹션 순서 재편. 기존 §1(행동 성향), §2(Agent-Relevant Capability Composite)를 §3, §4로 후퇴시키고, 앞에 §1(벤치마크 역사), §2(측정 공백) 신설.

**변경 전 구조**:
1. 물려받는 경향
2. Agent-Relevant Capability Composite 정의 → 너무 일찍 등장
3. Capability Cliff
...

**변경 후 구조**:
1. LLM 평가의 역사 (MMLU → SWE-bench → AgentBench)
2. Agent 운용 관점의 측정 공백
3. 물려받는 경향 (이전 §1)
4. Agent-Relevant Capability Composite (이전 §2, 이제 §4에 위치)
5. Capability Cliff
...

**이유**:

1. **독자 공감 결여**: 이전 구조에서는 Agent-Relevant Capability Composite가 독자가 기존 벤치마크의 한계를 충분히 체감하기 전에 등장했다. "왜 새 측정이 필요한가"에 대한 답이 없는 상태에서 새 개념이 소개되면 장벽으로 느껴진다.

2. **보편성 근거 없음**: Agent-Relevant Capability Composite의 네 차원(Tool Call Accuracy, Instruction Following Rate, Multi-Step Reasoning Depth, Context Utilization Efficiency)이 왜 올바른 분해인지를 기존 문헌 없이 주장하면 독자는 "왜 다섯 개가 아닌가"라는 질문을 갖는다. 벤치마크 역사 리뷰가 이 근거를 제공한다.

3. **서사 방향 불일치**: 책의 기조가 "실패담 → 처방"이 아닌 "기술 고도화 소개"로 재정렬되면서, Ch.2도 "측정 기술이 어떻게 발전해왔는가"에서 시작하는 것이 일관성 있다.

4. **리뷰 논문 스타일 도입**: 초반 챕터는 기존 지식을 집대성하는 리뷰 논문 스타일로 접근성을 높인다. 독자가 이 분야를 처음 접하는 경우에도 역사적 맥락에서 개념을 소화할 수 있다.

**영향 범위**: `chapter-map.md`, `chapters/ch02-nature-agent-inherits.md` outline 개정.

## SD-002 — 전체 서사 방향 전환: 실패담 → 기술 고도화 소개

**날짜**: 2026-03-27
**변경 내용**: 책 전체의 서사 프레임을 "무엇이 부서졌는가 → 어떻게 고쳤는가"에서 "기술이 어디까지 왔는가 → 어떤 운영 과제가 열렸는가 → 이것이 우리가 만든 접근이다"로 재정렬.

**이유**:

1. **공감 구조의 차이**: 실패담 프레임은 필자가 겪은 특정 실패를 공유하지 않은 독자에게 거리감을 만든다. 기술 발전 소개 프레임은 독자가 이미 알고 있는 기술 흐름에서 시작해 자연스럽게 과제로 이동한다.

2. **레퍼런싱 가능성**: 기술 고도화 서사는 GitHub, 공식 문서, 논문으로 레퍼런싱할 수 있는 사실 기반 진술을 앞에 배치한다. 실패담은 개인 관찰이라 외부 검증이 어렵다.

3. **접근성**: 실패담이 앞에 오면 "이 저자의 특수한 경험"으로 읽힌다. 기술 역사 리뷰가 앞에 오면 "내가 이미 알고 있는 것의 정리"로 읽혀 진입 장벽이 낮다.

**Ch.1 처리**: Ch.1은 이미 v0.2 초고 완료 상태. §4(harness 없는 장기 운용)의 톤을 기술적 관찰 기록으로 유지하되, 실패담 프레임이 아닌 "이 조건에서 어떤 일이 일어나는가"의 분석 기록으로 재포지셔닝. 전면 재작성 불필요.

**영향 범위**: `chapter-map.md` Ch.1 핵심 메시지 및 탐구 질문 갱신 완료.

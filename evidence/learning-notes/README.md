## 이 기록이 책에 반영되는 방식

1. 각 Learning Note는 해당 챕터 파일에 `<!-- LN: [개념명] -->` 주석으로 연결된다.
2. `/draft` 실행 시, 해당 섹션과 연결된 Learning Note가 있으면 참조할 수 있다.
3. "출발점 → 전환점 → 현재 이해" 구조는 독자의 이해 경로를 설계하는 데 사용된다.
4. "아직 불확실한 것"은 실험 설계(E01-E22)나 추가 deep research의 출발점이 된다.
